# Call Analysis Pipeline

Автоматическая система анализа телефонных разговоров колл-центра медицинской клиники.

## Возможности
- Транскрибация русской речи (GigaAM v3)
- Распознавание эмоций в голосе (GigaAMEmo)
- Смысловой анализ диалога: цель звонка, вежливость, чек-лист (Saiga LLM)
- Хранение результатов в PostgreSQL
- Дашборд на Streamlit

## Требования
- Linux-сервер с CPU (рекомендуется 80+ ядер для максимальной производительности, 64+ ГБ ОЗУ)
- Python 3.12
- ffmpeg
- PostgreSQL 15+
- MySQL (исходная БД с метаданными)

## Установка и запуск

1. Клонировать репозиторий:
 ```git clone <repo_url> && cd SpeechAn```

2. Выполнить скрипт автоматической установки (Ubuntu):
 ```bash scripts/setup_ubuntu.sh```
 Скрипт установит все системные зависимости, Python 3.12, настроит БД и скачает LLM модель.

3. Настроить конфигурацию в ```/opt/calls/.env```.

4. Запустить систему как сервис:
 ```sudo systemctl start call_analysis.service```

## Управление системой

Система работает как единый сервис, запускающий диспетчер задач и веб-интерфейс.

- Запуск: ```sudo systemctl start call_analysis.service```
- Остановка: ```sudo systemctl stop call_analysis.service```
- Перезапуск: ```sudo systemctl restart call_analysis.service```
- Просмотр логов: ```journalctl -u call_analysis -f```
- Статус: ```sudo systemctl status call_analysis.service```

## Загрузка моделей

Система использует три модели. Путь для хранения моделей по умолчанию – каталог ```/opt/calls/models/```.

### 1. GigaAM (ASR)
- Используется модель ```v3_e2e_ctc```.
- Загружается автоматически при первом запуске.

### 2. GigaAMEmo (Сбер)
- Загружается автоматически при первом запуске.

### 3. Saiga/Llama3 8B (GGUF)
- Файл ```model-q4_K.gguf``` скачивается автоматически скриптом ```setup_ubuntu.sh```.
- Путь к файлу задаётся в ```.env``` переменной ```LLM_MODEL_PATH```.

## Структура БД (PostgreSQL)
- ```calls``` – метаданные звонка, статус обработки, длительность анализа.
- ```transcripts``` – расшифровка диалога.
- ```evaluations``` – итоговые оценки LLM и данные по эмоциям (столбец ```speech_emotions```).
- ```phones``` – справочник внутренних номеров для фильтрации.
- ```prompts``` – шаблоны анализа.
- ```system_settings``` – глобальные флаги (вкл/выкл системы, пропуск локальных звонков).

## Примечание
- Обработка аудио происходит полностью в оперативной памяти.
- Система автоматически адаптируется под количество ядер процессора.
- Для фильтрации звонков используется таблица ```phones```. Если номера нет в таблице или ```use = false```, звонок не обрабатывается.
- Локальные звонки (между сотрудниками) могут игнорироваться при включении соответствующей настройки в БД.
