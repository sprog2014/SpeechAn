# Обзор архитектуры (Architecture Review)

Система SpeechAn предназначена для автоматического анализа звонков в медицинских клиниках.

## Технологический стек
- **Язык**: Python 3.12
- **Транскрибация**: GigaAM v3 (CTC)
- **LLM**: Saiga Llama 3 8B (через llama-cpp-python)
- **База данных**: PostgreSQL 15 + MySQL (источник)
- **Интерфейс**: Streamlit

## Процесс обработки (Pipeline)
1. **Сбор данных**: Диспетчер сканирует сетевую папку с записями mp3 и сравнивает их с БД.
2. **Транскрибация**:
   - Аудио загружается и ресемплируется до 16кГц с помощью `torchaudio`.
   - Используется кастомная сегментация на базе VAD для разделения диалога на реплики.
   - Каждый сегмент распознается моделью GigaAM v3.
3. **LLM Анализ**:
   - Полная расшифровка диалога передается в LLM.
   - LLM извлекает структурированную информацию: вежливость, цель, статус записи, жалобы.
   - Результат извлекается из JSON-ответа модели.
4. **Хранение**: Результаты сохраняются в PostgreSQL.

## Схема БД
- `calls`: Основная таблица с метаданными звонков.
- `transcripts`: Посегментная расшифровка текста.
- `evaluations`: Результаты анализа LLM.
- `processing_stats`: Время выполнения каждого этапа для статистики.
