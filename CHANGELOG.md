# Журнал изменений (CHANGELOG)

Все заметные изменения в проекте Call Analysis Pipeline будут документироваться в этом файле.

## [1.0.0] - 2024

### Архитектура и Диспетчеризация
- **Разделение конвейеров**: ASR (распознавание) и LLM (анализ) разделены на два независимых диспетчера (`asr_dispatcher.py` и `llm_dispatcher.py`). Это позволяет независимо масштабировать ресурсы и повышает стабильность системы.
- **Многопроцессорность**: Использование `ProcessPoolExecutor` с режимом `spawn` и ограничением `max_tasks_per_child=5` для предотвращения утечек памяти и обеспечения изоляции моделей.
- **Оптимизация CPU**: Настройка параметров OpenVINO (`OV_CPU_INFERENCE_NUM_THREADS`, `OV_CPU_BIND_THREAD`, `OV_CPU_ENABLE_NUMA=NO`) для максимальной производительности на многоядерных серверах.
- **Управление задачами**: Добавлена система фоновых задач для обработки исторических данных через таблицу `tasks` в БД.
- **Очистка при запуске**: Автоматическое удаление зависших записей со статусом `processing` при перезагрузке системы.

### ASR (Автоматическое распознавание речи)
- **GigaAM v3**: Интеграция модели `v3_e2e_ctc` от Сбера.
- **Улучшенный VAD**: Реализован собственный детектор голосовой активности на основе энергии для точного разделения диалога на реплики оператора и клиента.
- **Параллельная обработка каналов**: Стерео-каналы (оператор/клиент) обрабатываются параллельно внутри одного воркера.
- **Нормализация аудио**: Добавлена независимая пиковая нормализация каналов перед распознаванием для улучшения качества транскрибации тихого голоса.
- **In-memory обработка**: Все промежуточные этапы (разделение каналов, VAD) выполняются в оперативной памяти без записи временных файлов на диск.

### LLM (Языковая модель и анализ)
- **Qwen2.5-7B-Instruct**: Переход на использование модели Qwen2.5, оптимизированной через OpenVINO (INT8).
- **Промпты и оценки**: Реализована гибкая система шаблонов анализа (цель звонка, вежливость, чек-лист) с хранением результатов в таблице `evaluations`.
- **Фильтрация по номерам**: Интеграция с таблицей `phones` для автоматического пропуска звонков с внутренних или нецелевых номеров (с возможностью принудительного анализа всех звонков в задачах).

### Дашборд (Streamlit)
- **Аналитика**: Создана страница аналитики с визуализацией распределения целей звонка, настроения клиентов и вежливости операторов.
- **Статистика**: Добавлена детальная страница мониторинга состояния системы (очередь, обработанные файлы, ошибки).
- **Интерактивные фильтры**: Реализована система кросс-фильтрации между графиками (выбор сегмента на графике фильтрует таблицу звонков).
- **Локализация**: Полный перевод интерфейса на русский язык.
- **Плеер**: Интегрировано прослушивание записей непосредственно из дашборда с привязкой к `linkedid`.

### Инфраструктура и БД
- **Системная служба**: Создан `call_analysis.service` для управления системой через `systemctl`.
- **Автоматизация развертывания**: Скрипт `scripts/setup_ubuntu.sh` для полной настройки окружения, Python 3.12 и конвертации моделей.
- **Схема БД**: Оптимизирована структура PostgreSQL, добавлены таблицы для статистики обработки (`processing_stats`), задач (`tasks`) и промптов (`prompts`).
- **Удаление лишнего**: Полностью удален функционал анализа эмоций (GigaAMEmo) для упрощения системы и экономии ресурсов.
